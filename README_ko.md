# 음성 입력 사용 설명서

## 1. 소프트웨어 소개

Windows 플랫폼용 음성 입력기로, 타사 ASR(음성 인식) API에 연결됩니다. 단축키를 눌러 녹음을 시작하고, 다시 누르면 녹음이 중지되며 인식된 텍스트가 현재 커서 위치에 자동으로 입력됩니다.

## 2. 핵심 기능

- 음성을 텍스트로: 전역 단축키로 녹음을 트리거하며, 인식 결과를 커서 위치에 자동으로 붙여넣습니다
- 다중 서비스 제공자 지원: OpenAI 호환 형식, 더우바오 대규모 모델, 화산엔진 세 가지 ASR 서비스 지원
- 플로팅 창: 녹음 중 실시간 상태 표시(테마색 얇은 테두리 포함), 결과는 클립보드에 자동 복사 후 붙여넣기
- 기록: 매 인식 결과를 자동으로 저장하며, 단락 들여쓰기 형식 지원
- 다국어 인터페이스: 35종의 인터페이스 언어 내장, 가장 적합한 글꼴 자동 매칭
- 테마 전환: 밝은 / 어두운 두 가지 테마 지원, 모든 컨트롤 색상을 일괄 새로고침
- 글자 크기 조정: 위아래 화살표로 글자 크기 등급 조절(8 ~ 15, 기본 10), 글꼴에만 영향 컨트롤에는 영향 없음
- 단축키 사용자 정의: "수정" 버튼 클릭 후 팝업 창에서 조합키를 눌러 캡처, 1 ~ 3키 조합 지원
- 핫워드 치환: 생소한 단어를 핫워드 표에 등록, 음소 기반 퍼지 매칭으로 강제 치환
- 정규표현식 규칙 치환: 등식 또는 정규표현식 규칙으로 지정된 텍스트를 정확히 치환
- ITN 숫자 변환: "십오육 개"를 "15~16개"로 자동 변환, 범위·날짜·퍼센트·분수 등 지원; "잠깐만""같이" 등 보호어 내장으로 오변환 방지
- 감탄사 제거: "어, 아, 음" 등 구어 감탄사를 자동으로 제거(LLM에 의존하지 않고 순수 로컬 처리)
- LLM 역할 처리: 인식 결과가 역할명으로 시작할 경우 해당 대규모 모델 역할이 처리(윤문·번역·비서 등); 역할 파일은 AST로 안전하게 파싱, 리터럴 대입만 허용
- 음성 명령: "실행 취소""줄바꿈""백스페이스" 등 명령을 말하면 해당 작업 자동 실행
- 일기 보관: 날짜별로 매 음성 입력 및 인식 결과 저장
- 부팅 시 자동 실행: 부팅 시 자동 시작 선택 가능
- 시스템 트레이: 트레이로 최소화, 왼쪽 클릭으로 주 창 열기, 오른쪽 클릭으로 종료

## 3. 빠른 시작

1. 프로그램 시작 후 기본적으로 시스템 트레이로 최소화됩니다
2. 트레이 아이콘을 왼쪽 클릭하여 주 창을 엽니다
3. 첫 사용 전, "AI 설정" 페이지에서 ASR 서비스 제공자와 API 키를 입력합니다
4. 텍스트를 입력할 수 있는 임의의 창에서, 커서를 입력할 위치에 놓습니다
5. `Ctrl+Alt`를 눌러 녹음을 시작합니다(트레이 아이콘이 빨간색으로 변하고 플로팅 창이 나타남)
6. 마이크를 향해 말합니다
7. 다시 `Ctrl+Alt`를 눌러 녹음을 중지합니다
8. 인식 결과가 커서 위치에 자동으로 붙여넣어집니다

> 팁: API를 설정하지 않고 단축키로 녹음하면 플로팅 창에 "AI 미설정"이라고 표시됩니다. 먼저 설정을 완료하세요.

## 4. 인터페이스 설명

주 창 왼쪽은 내비게이션 바로, 다음 페이지들을 포함합니다:

- 홈: 녹음 상태와 최근 인식 결과 표시, 복사 버튼 제공
- 로그: 프로그램 실행 로그를 실시간 표시, 녹음·인식·후처리 각 단계 정보 포함
- 기록: 과거 인식 기록 열람, 복사 및 단락 들여쓰기 표시 지원
- AI 설정: ASR 서비스 제공자, API 주소 및 키, 모델명 등 입력; "텍스트 윤문 활성화"와 "LLM 역할 활성화" 스위치 포함
- 도구 상자: 각 텍스트 후처리 기능의 중앙 스위치(끝 문장부호 제거·ITN·감탄사 제거·핫워드·정규표현식 규칙·일기 보관)
- 설정: 일반 설정, 단축키·테마·글자 크기·인터페이스 언어·부팅 시 자동 실행·플로팅 창 등 포함

## 5. 설정 항목 상세

### ASR 관련(AI 설정 페이지)

| 설정 항목 | 기능 |
| --- | --- |
| ASR 서비스 제공자 | 음성 인식 서비스 선택: openai_compatible(OpenAI 호환), doubao(더우바오), volcengine(화산엔진) |
| base_url | OpenAI 호환 API의 기본 주소 |
| api_key | OpenAI 호환 API의 키 |
| model | 모델명, 예: whisper-1 |
| app_key | 더우바오 / 화산의 애플리케이션 키 |
| access_key | 더우바오 / 화산의 액세스 키 |
| resource_id | 더우바오 리소스 ID |
| cluster | 화산엔진 클러스터명 |
| asr_mode | ASR 인식 모드 |
| 텍스트 윤문 활성화 | 마스터 스위치, 끄면 LLM 호출 안 함 |
| LLM 역할 활성화 | 텍스트 윤문이 켜져 있을 때만 선택 가능, 꺼져 있으면 회색 표시 |

| 설정 항목 | 기능 |
| --- | --- |

| 테마 | 밝게(light) 또는 어둡게(dark), 기본 어둡게 |

## 7. 자주 묻는 질문

### 1. 단축키를 눌러도 반응이 없나요?

- 소프트웨어가 시스템 트레이에서 실행 중인지 확인(트레이 아이콘이 회색이면 준비 상태)
- 단축키가 다른 소프트웨어에 의해 점유되지 않았는지 확인
- "설정" 페이지에 들어가 단축키 옆의 "수정" 버튼 클릭, 팝업 창에서 조합키 다시 누르기
- 로그 페이지에 오류 메시지가 있는지 확인

### 2. 인식 실패 시 어떻게 하나요?

- "AI 설정" 페이지에 입력한 API 키, 주소, 모델이 올바른지 확인
- 네트워크 연결이 정상인지 확인
- "로그" 페이지를 열어 구체적인 오류 메시지 확인
- 마이크가 정상 작동하고 말하는 볼륨이 충분한지 확인

### 3. 글자 크기는 어떻게 조절하나요?

"설정" 페이지에 들어가 "글자 크기" 설정 항목을 찾은 뒤, 오른쪽 위아래 화살표로 등급을 조절합니다(8 ~ 15, 기본 10). 숫자가 클수록 글자가 큽니다. 이 설정은 글꼴에만 영향을 미치며 버튼 등 컨트롤 크기는 변경하지 않고, 조정 후 프로그램 재시작으로 적용됩니다.

### 4. 단축키는 어떻게 사용자 정의하나요?

"설정" 페이지에 들어가 "단축키" 설정 항목을 찾은 뒤, 오른쪽 "수정" 버튼을 클릭하여 팝업 독립 창에서 원하는 조합키를 누릅니다(1 ~ 3키 지원, 예: Ctrl+Shift+V). 캡처 완료 후 "확인"을 클릭하여 저장하면, 프로그램 재시작 후 새 단축키가 적용됩니다.

### 5. 인식 결과가 자동으로 붙여넣어지지 않나요?

- 대상 창이 붙여넣기 작업을 지원하는지 확인
- 커서가 입력 가능 영역에 놓여 있는지 확인
- 플로팅 창을 껐다면 인식 결과는 주 창 텍스트 상자에만 표시되며, 복사 버튼을 수동으로 클릭해야 합니다

### 6. 생소한 단어를 추가해 인식을 더 정확하게 하려면?

`config/hot.txt` 파일을 직접 편집하여 한 줄에 하나의 핫워드를 작성합니다. 동시에 `config/hot-rule.txt`에서 등식 또는 정규표현식 규칙으로 정확한 치환을 할 수 있습니다.

### 7. LLM 역할은 어떻게 사용하나요?

`config/roles/` 디렉터리에 `.py` 파일을 생성하고, 파일 내에서 변수 대입으로 역할 속성(name, trigger_words, system_prompt, output_mode 등)을 정의합니다. 역할 파일은 AST로 안전하게 파싱되며 리터럴 대입만 허용되고 함수 호출이나 임의의 코드는 작성할 수 없습니다. 인식 결과가 역할명으로 시작하면 해당 역할이 자동으로 트리거됩니다.
