# 音声入力 使用説明

## 一、ソフトウェア紹介

本ソフトウェアは Windows プラットフォーム向けの音声入力メソッドです。サードパーティの ASR（音声認識）API に接続し、ホットキーを押すと録音を開始し、もう一度ホットキーを押すと録音を停止し、認識されたテキストを現在のカーソル位置に自動入力します。

## 二、コア機能

- 音声からテキストへ：グローバルホットキーで録音をトリガーし、認識結果をカーソル位置に自動貼り付け
- 複数プロバイダ対応：OpenAI 互換形式、豆包大モデル、火山エンジンの 3 種類の ASR サービスに対応
- フローティングウィンドウ：録音時にリアルタイムステータスを表示（テーマ色の細い枠線付き）、結果は自動的にクリップボードへコピーされ貼り付け
- 履歴記録：毎回の認識結果を自動保存、段落インデント形式をサポート
- 多言語インターフェース：35 種類のインターフェース言語を内蔵、最適なフォントを自動マッチング
- テーマ切替：ライト / ダーク 2 種類のテーマをサポート、すべてのコントロールの色を統一更新
- フォントサイズ調整：上下矢印でフォントサイズレベルを調整（8 ~ 15、デフォルト 10）、フォントのみに影響しコントロールには影響しない
- ホットキーカスタマイズ：「変更」ボタンをクリックしてポップアップで組み合わせキーを押下してキャプチャ、1 ~ 3 キーの組み合わせをサポート
- ホットワード置換：レア語をホットワード表に書き込み、音素による曖昧マッチングで強制置換
- 正則表現ルール置換：等式または正則表現ルールで指定テキストを正確に置換
- ITN 数値変換：「十五六个」を自動的に「15~16个」に変換、範囲、日付、パーセンテージ、分数などをサポート；誤変換を防ぐための保護語を内蔵（「一会儿」「一样」など）
- フィラーワード除去：「呃、啊、嗯」などの口頭フィラーワードを自動削除（LLM に依存せず、純ローカル処理）
- LLM キャラクター処理：認識結果がキャラクター名で始まる場合、対応する大モデルキャラクターに処理を委譲（推敲、翻訳、アシスタントなど）；キャラクターファイルは AST で安全に解析、リテラル代入のみ許可
- 音声コマンド：「撤销」「换行」「退格」などのコマンドを発話すると、対応する操作を自動実行
- 日記アーカイブ：日付ごとに毎回の音声入力と認識結果を保存
- 起動時自動起動：PC 起動時の自動起動を選択可能
- システムトレイ：トレイに最小化、左クリックでメインウィンドウを開く、右クリックで終了

## 三、クイックスタート

1. プログラム起動後、ソフトウェアはデフォルトでシステムトレイに最小化されます
2. トレイアイコンを左クリックしてメインウィンドウを開きます
3. 初回使用前に「AI 設定」ページで ASR プロバイダと API キーを入力します
4. テキストを入力できる任意のウィンドウで、カーソルを入力位置に置きます
5. `Ctrl+Alt` を押して録音を開始します（トレイアイコンが赤くなり、フローティングウィンドウが表示されます）
6. マイクに向かって話します
7. もう一度 `Ctrl+Alt` を押して録音を停止します
8. 認識結果がカーソル位置に自動貼り付けされます

> ヒント：API を設定せずにホットキーで録音すると、フローティングウィンドウに「AI 未設定」と表示されます。先に設定を完了してください。

## 四、インターフェース説明

メインウィンドウ左側はナビゲーションバーで、以下のページを含みます：

- ホーム：録音ステータスと直近の認識結果を表示、コピーボタンを提供
- ログ：プログラム実行ログをリアルタイム表示、録音、認識、後処理の各段階情報を含む
- 履歴：履歴認識記録の閲覧、コピーと段落インデント表示をサポート
- AI 設定：ASR プロバイダ、API アドレスとキー、モデル名などを入力；「テキスト推敲を有効化」と「LLM キャラクターを有効化」スイッチを含む
- ツールボックス：各テキスト後処理機能のスイッチを集約（末尾句読点除去、ITN、フィラーワード除去、ホットワード、正則表現ルール、日記アーカイブ）
- 設定：一般設定、ホットキー、テーマ、フォントサイズ、インターフェース言語、起動時自動起動、フローティングウィンドウなどを含む

## 五、設定項目詳細

### ASR 関連（AI 設定ページ）

| 設定項目 | 作用 |
| --- | --- |
| ASR プロバイダ | 音声認識サービスを選択：openai_compatible（OpenAI 互換）、doubao（豆包）、volcengine（火山エンジン） |
| base_url | OpenAI 互換 API のベースアドレス |
| api_key | OpenAI 互換 API のキー |
| model | モデル名、例：whisper-1 |
| app_key | 豆包 / 火山のアプリケーションキー |
| access_key | 豆包 / 火山のアクセスキー |
| resource_id | 豆包リソース ID |
| cluster | 火山エンジンクラスタ名 |
| asr_mode | ASR 認識モード |
| テキスト推敲を有効化 | メインスイッチ、オフにすると LLM を呼び出さない |
| LLM キャラクターを有効化 | テキスト推敲がオンの場合のみ選択可能、オフ時はグレーアウト |

### 一般設定（設定ページ）

| 設定項目 | 作用 |
| --- | --- |
| ホットキー | 録音をトリガーするグローバルホットキー、デフォルト Ctrl+Alt；「変更」をクリックしてポップアップで新しい組み合わせをキャプチャ |
| テーマ | ライト（light）またはダーク（dark）、デフォルトはダーク |
| フォントサイズ | フォントサイズレベル 8 ~ 15、デフォルト 10；上下矢印で調整、フォントのみに影響しコントロールには影響しない、再起動後に反映 |
| インターフェース言語 | インターフェース表示言語を切替、全 35 種類から選択可能 |
| 起動時自動起動 | オンにすると PC 起動時にプログラムを自動起動 |
| フローティングウィンドウ | オンにすると録音時にフローティングウィンドウを表示（テーマ色の細い枠線付き）；オフにすると結果はメインウィンドウのテキストボックスにのみ表示 |

### テキスト後処理スイッチ（ツールボックスページ）

| 設定項目 | 作用 | デフォルト |
| --- | --- | --- |
| 末尾句読点除去 | 認識結果末尾のコンマ、句点を自動削除 | オン |
| ITN 数値変換 | 「十五六个」を「15~16个」などの数値形式に変換；誤変換を防ぐ保護語を内蔵（「一会儿」「一样」など） | オン |
| フィラーワード除去 | 「呃、啊、嗯」などの口頭フィラーワードを自動削除（純ローカル処理、LLM に依存しない） | オン |
| ホットワード置換 | 音素による曖昧マッチングでレア語を強制置換 | オン |
| ホットワードマッチング閾値 | ホットワード類似度閾値、0.0~1.0、大きいほど厳格 | 0.85 |
| 正則表現ルール置換 | 等式または正則表現ルールでテキストを正確に置換 | オン |
| 日記アーカイブ | 日付ごとに毎回の音声入力と認識結果を保存 | オン |

> LLM 関連スイッチ（テキスト推敲を有効化、LLM キャラクターを有効化）は「AI 設定」ページにあり、ツールボックスにはありません。

## 七、よくある質問

### 1. ホットキーを押しても反応がない？

- ソフトウェアがシステムトレイで実行中か確認（トレイアイコンがグレーは準備完了を示す）
- ホットキーが他のソフトウェアに占有されていないか確認
- 「設定」ページに入り、ホットキー横の「変更」ボタンをクリック、ポップアップで組み合わせキーを再度押下
- ログページにエラー表示がないか確認

### 2. 認識失敗時の対処？

- 「AI 設定」ページで入力した API キー、アドレス、モデルが正しいか確認
- ネットワーク接続が正常か確認
- 「ログ」ページを開いて具体的なエラー情報を確認
- マイクが正常に動作しているか、話す音量が十分か確認

### 3. フォントサイズの調整方法？

「設定」ページに入り、「フォントサイズ」設定項目を探し、右側の上下矢印でレベルを調整（8 ~ 15、デフォルト 10）。数値が大きいほどフォントが大きくなります。この設定はフォントのみに影響し、ボタンなどコントロールのサイズは変更しません。調整後、プログラムの再起動で反映されます。

### 4. ホットキーのカスタマイズ方法？

「設定」ページに入り、「ホットキー」設定項目を探し、右側の「変更」ボタンをクリック、ポップアップの独立ウィンドウで希望する組み合わせキーを押下（1 ~ 3 キーをサポート、例：Ctrl+Shift+V）。キャプチャ完了後「確認」をクリックして保存、プログラム再起動後に新ホットキーが有効になります。

### 5. 認識結果が自動貼り付けされない？

- 対象ウィンドウが貼り付け操作をサポートしているか確認
- カーソルが入力可能領域に置かれているか確認
- フローティングウィンドウをオフにした場合、認識結果はメインウィンドウのテキストボックスにのみ表示され、手動でコピーボタンをクリックする必要があります

### 6. レア語を追加して認識精度を上げるには？

`config/hot.txt` ファイルを直接編集、1 行に 1 つのホットワード。同時に `config/hot-rule.txt` で等式または正則表現ルールによる正確な置換が可能です。

### 7. LLM キャラクターの使い方？

`config/roles/` ディレクトリに `.py` ファイルを作成、ファイル内で変数代入によりキャラクター属性（name、trigger_words、system_prompt、output_mode など）を定義。キャラクターファイルは AST で安全に解析、リテラル代入のみ許可、関数呼び出しや任意コードは記述不可。認識結果がキャラクター名で始まる場合、対応するキャラクターが自動トリガーされます。
